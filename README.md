# 🕉️ Mahabharatham Quiz Adventure (మహాభారతం క్విజ్ అడ్వెంచర్)

An immersive, illustrated 100-level storybook quiz adventure exploring the timeless epic of the Mahabharata.

## ✨ Features

- **📖 100 Progressive Levels**: Spanning 10 monumental story parts (Adi Parva to Svargarohana Parva).
- **🎨 Premium Illustrated Storybook**: Rich cinematic illustrations and narrative lore before every chapter.
- **🌐 Trilingual Support**: Fully playable in **English**, **Telugu (తెలుగు)**, and **Hindi (हिन्दी)**.
- **🏆 Official Mahabharata Scholar Certificate**: High-resolution downloadable PDF certificate with dynamic user name upon completing all 100 levels.
- **⚔️ Character Wallpapers & Rewards**: Unlock sacred wallpapers for legendary figures (Lord Krishna, Arjuna, Bhima, Karna, Bhishma, Draupadi, Abhimanyu, Dronacharya, Yudhishthira, Sanatana Dharma).
- **💎 Gamification**: XP, Coins, Lifelines (50-50, Skip, Hint), Combo multipliers, Streaks, and Level milestones.
- **📱 Fully Responsive**: Optimized for all devices from smartphones to desktop displays.

## 🚀 Tech Stack

- **React 18** with **TypeScript**
- **Vite** for fast builds and hot module reloading
- **Tailwind CSS** for custom mythological theming and styling
- **Lucide Icons** & **Canvas Confetti**
- **jsPDF** for dynamic, high-resolution certificate generation

## 🛠️ Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

```bash
# Clone the repository
git clone https://github.com/raghavendra1234098-sudo/mahabharatham-quiz-adventure.git

# Navigate into the project directory
cd mahabharatham-quiz-adventure

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Building for Production

```bash
npm run build
```
